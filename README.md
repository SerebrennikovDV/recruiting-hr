# UnitHire — рекрутинговая информационная система с HR-аналитикой

Веб-сервис для автоматизации процесса подбора персонала и анализа эффективности
рекрутинга в ООО «ЮНИТКОД». Разработан в рамках преддипломной практики по
направлению **38.03.05 «Бизнес-информатика»** (профиль «Цифровая экономика»),
МУ им. С. Ю. Витте.

**Тема ВКР:** «Проектирование рекрутинговой информационной системы на основе
HR-аналитики».
**Автор:** Серебренников Дмитрий Валерьевич.

## Возможности

- **Публичная часть** (более 10 страниц без авторизации): главная, каталог
  вакансий с поиском и фильтрами, карточка вакансии, новости/блог, разделы для
  соискателей и работодателей, демонстрация HR-аналитики, форма обратной связи,
  справка по системе.
- **Три роли с разграничением прав:** администратор, рекрутёр (HR-менеджер),
  кандидат (соискатель).
- **Кабинет рекрутёра:** управление вакансиями и кандидатами (CRUD), канбан
  откликов по этапам воронки, планирование собеседований, дашборды HR-аналитики
  со **сравнением с бенчмарками отрасли**, выгрузка отчётов в Excel и карточек
  кандидатов в Word.
- **Кабинет кандидата:** профиль, загрузка резюме с UUID-именем и MIME-валидацией,
  отклики на вакансии и **отслеживание их статусов и этапов с цветовой индикацией**,
  расписание собеседований.
- **Панель администратора** (Django admin) с кастомными массовыми действиями.
- **HR-аналитика:** воронка подбора, time-to-hire, cost-per-hire, конверсия
  источников, загрузка рекрутёров, динамика откликов, сравнение с бенчмарками
  индустрии (hh.ru research, AIHR, Хабр Карьера).

## Установка и запуск (локально)

```bash
git clone https://github.com/SerebrennikovDV/recruiting-hr.git
cd recruiting-hr

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Сервис доступен по http://127.0.0.1:8000/.

## Развёртывание на Yandex Cloud

Сервис развёрнут на Yandex Cloud (Compute Cloud VM Ubuntu 22.04 LTS +
PostgreSQL 15 в Docker). Деплой через Docker Compose: контейнер `web`
(Django + gunicorn) + `nginx` (reverse proxy на порту 80) + `db`
(PostgreSQL 15-alpine).

Пошаговая инструкция — в файле `ИНСТРУКЦИЯ_YANDEX_CLOUD.md` корневой
папки работы.

Краткий цикл деплоя:
```bash
cp .env.example .env
# Отредактируй: DJANGO_SECRET_KEY, POSTGRES_PASSWORD, DATABASE_URL
chmod 600 .env
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py seed_demo
```

Сервис доступен по `http://<IP-VM>/`.
