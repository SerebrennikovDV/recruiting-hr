# UnitHire — рекрутинговая информационная система с HR-аналитикой

Веб-сервис для автоматизации процесса подбора персонала и анализа эффективности
рекрутинга в ООО «ЮНИТКОД». Разработан в рамках преддипломной практики по
направлению **38.03.05 «Бизнес-информатика»** (профиль «Цифровая экономика»),
МУ им. С. Ю. Витте.

HR-аналитики».

## Возможности

- **Публичная часть** (более 10 страниц без авторизации): главная, каталог
  вакансий с поиском и фильтрами, карточка вакансии, новости/блог, разделы для
  соискателей и работодателей, демонстрация HR-аналитики, форма обратной связи,
  справка по системе.
- **Три роли с разграничением прав:** администратор, рекрутёр (HR-менеджер),
  кандидат (соискатель).
- **Кабинет рекрутёра:** управление вакансиями и кандидатами (CRUD), канбан
  откликов по этапам воронки, планирование собеседований, дашборды HR-аналитики,
  выгрузка отчётов в Excel и карточек кандидатов в Word.
- **Кабинет кандидата:** профиль, загрузка резюме (доступ к файловой системе),
  отклики на вакансии и отслеживание их статусов, расписание собеседований.
- **Панель администратора** (Django admin) с кастомными массовыми действиями
  («Закрыть выбранные вакансии», «Отправить кандидатов в архив» и др.).
- **HR-аналитика:** воронка подбора, time-to-hire, cost-per-hire, конверсия
  источников, загрузка рекрутёров, динамика откликов (агрегатные SQL-запросы).

## Установка и запуск (локально)

```bash
# 1. Клонировать репозиторий
git clone <URL-репозитория>
cd recruiting-hr

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. (необязательно) Настроить .env по образцу .env.example
cp .env.example .env

# 5. Применить миграции и загрузить демонстрационные данные
python manage.py migrate
python manage.py seed_demo

# 6. Запустить сервер
python main.py
#   или: python manage.py runserver
```

После запуска сервис доступен по адресу <http://127.0.0.1:8000/>.

Файл **`main.py`** в корне репозитория выполняет полный цикл запуска: применяет
миграции, при пустой базе загружает демо-данные и поднимает веб-сервер.

## Основные сценарии использования

- **Соискатель:** регистрация → заполнение профиля → загрузка резюме → отклик на
  вакансию → отслеживание статуса.
- **Рекрутёр:** создание вакансии → просмотр откликов на канбан-доске → перевод
  кандидата по этапам → назначение собеседования → анализ метрик → выгрузка отчёта.
- **Администратор:** управление пользователями, справочниками и контентом,
  массовые операции над вакансиями и кандидатами.

## Развёртывание

Сервис развёртывается на бесплатном плане **Render.com** (см. `render.yaml`):
сборка выполняется скриптом `build.sh`, запуск — через gunicorn, статику отдаёт
WhiteNoise, база данных — управляемый PostgreSQL Render.
